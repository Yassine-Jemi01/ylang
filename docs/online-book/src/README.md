# The YLang Book

Welcome to **The YLang Book**, the guided online guide to the YLang programming language and compiler.

This is a real multi-page HTML book—not a raw Markdown page or a list of links. Use the chapter sidebar to move through the material, search the book, switch its appearance, copy code examples, or move to the previous and next chapter. Reference chapters are generated from the canonical files in `docs/`, so the language specification and implementation guides remain maintained in one place.

## Choose the right version

- **Stable line — 1.1.0:** the conservative, documented language subset.
- **Preview line — 2.0.0-beta.2:** adds named imports and multi-file compilation, experimental typed structs and enums, optional SDL2 GUI/Game2D helpers, a Linux YSPM package, and an experimental native Windows path.

The 2.0 beta is for evaluation and feedback. Structs, enums, imports, GUI/Game2D, NASM, and native Windows support have explicit limitations; the beta is not a promise of production stability or Rust-level memory safety.
