# نموذج الأمان

**YLang مترجم وبرنامج بناء، وليس Sandbox.** يعمل الملف التنفيذي بصلاحيات المستخدم الذي شغّله. لا يعزل YLang الوصول إلى الملفات أو العمليات أو الشبكة أو المكتبات الأصلية التي يستدعيها البرنامج.

## حدود الموارد في المترجم

تضع YLang حدوداً لبعض المدخلات لتقليل استهلاك الذاكرة وعمق الاستدعاء عند التعامل مع مشاريع غير متوقعة:

- 100 تشخيص كحد أقصى لكل عملية ترجمة، ومقتطف سطر لا يتجاوز 160 Byte.
- حد أقصى 1,024 ملف مصدر مستورد.
- حجم إجمالي 64 MiB للمصدر الأساسي وجميع الملفات المستوردة.
- حد عمق استيراد 256 مستوى.
- حد تعشيش عبارات Parser قدره 256، وحارس 512 مستوى في Code Generation.
- حد JSON قدره 16 MiB للمدخل أو الناتج، و128 مستوى تعشيش.

تساعد هذه الحدود على منع استهلاك الموارد بلا نهاية، لكنها لا تمنح البرنامج التنفيذي عزلاً أو صلاحيات أقل.

## سلامة HTTP

تستخدم واجهة HTTP التجريبية libcurl وتطبق افتراضياً:

- قبول عناوين `http://` و`https://` فقط.
- التحقق من شهادة TLS واسم المضيف دون خيار Insecure bypass.
- مهلة اتصال 5 ثوانٍ ووقت إجمالي 15 ثانية للطلبات المخزنة.
- حد جسم استجابة 8 MiB وحد نص Headers قدره 16 KiB.
- حد خمسة Redirects، مع منع تمرير Headers الحساسة إلى وجهة جديدة.
- 32 HTTP Task كحد أقصى و16 Stream نشطاً، مع مخزن 64 KiB لكل Stream.

لا تجعل هذه القواعد أي URL آمناً في جميع التطبيقات. إذا كان برنامج الخادم يقبل URL من مستخدم، ضع Allow-list لأسماء المضيفين والعناوين، وانتبه إلى Loopback وPrivate وLink-local وعناوين Metadata.

## مفاتيح API

استخدم `env.get("SERVICE_API_KEY")` لقراءة المفتاح من بيئة العملية. إذا لم يوجد المتغير، تعيد الدالة نصاً فارغاً.

لا تضع مفاتيح حقيقية في Git أو أمثلة عامة، ولا تطبعها في Logs. استخدم أقل صلاحيات ممكنة للمفتاح، وغيّره إذا تسرّب.

## البرامج الأصلية والتصحيح

- `ylang build` ينتج برنامجاً يعمل بصلاحيات المستخدم.
- `ylang debug` ليس حدّاً أمنياً؛ أدوات GDB وLLDB تستطيع فحص حالة العملية وفق صلاحيات النظام.
- لا يدّعي YLang امتلاك أمان ذاكرة بمستوى Rust.
- استمر في استخدام Regression Tests وASan وUBSan وFuzzing على الأنظمة المدعومة.

لإبلاغ أمني، أرسل Commit المتأثر والنظام والـ Toolchain وأمر البناء وأصغر مصدر يعيد المشكلة. لا تنشر مفاتيح حقيقية أو بيانات خاصة في Issue. راجع [مرجع الأمان الإنجليزي](../reference/SECURITY.md).
