# برنامجك الأول

أنشئ ملفاً اسمه `hello.yl` واكتب فيه:

```ylang
function main() -> int {
    let const string name = "YLang";
    print("Hello from", name);
    print("The answer is", 40 + 2);
    return 0;
}
```

## ماذا يفعل البرنامج؟

- `function main() -> int` تعرّف دالة البداية وتحدد أن قيمة الإرجاع عدد صحيح.
- `let const string name` تنشئ متغيراً ثابتاً نوعه `string`.
- `print(...)` تطبع القيم في الطرفية.
- `return 0` تنهي البرنامج برمز نجاح.

## افحص وابنِ وشغّل

من مجلد المشروع نفّذ:

```sh
./build/ylang check hello.yl
./build/ylang build hello.yl -o hello
./hello
```

الأمر الأول يفحص المصدر دون إنشاء ملف تنفيذي. الأمر الثاني يستخدم C Backend الافتراضي ويستدعي GCC أو Clang لبناء البرنامج. الأمر الأخير يشغّل الناتج.

## جرّب بنفسك

غيّر قيمة `name` أو بدّل العملية `40 + 2` إلى عملية أخرى. أعد تنفيذ أوامر الفحص والبناء والتشغيل ولاحظ النتيجة.

إذا ظهر خطأ، اقرأ الرسالة الإنجليزية كاملة واحتفظ بكود التشخيص. لا تترجم نص رسالة المترجم أو تغيّره؛ الشرح العربي هنا لمساعدتك على فهم المفاهيم فقط.
