# الدوال والوحدات

تسمح الدوال بتجميع السلوك تحت أسماء واضحة، بينما تسمح الوحدات باستخدام تعريفات مختارة من ملفات `.yl` أخرى.

## الدوال

```ylang
function answer() -> int {
    return 42;
}

function main() -> int {
    print(answer());
    return 0;
}
```

يستدعي البرنامج الدالة باسمها والأقواس. إذا غيّرت توقيع دالة، افحص جميع المواضع التي تستدعيها.

## استيراد دالة من ملف آخر

افترض وجود ملف مجاور اسمه `math_tools.yl`:

```ylang
function answer() -> int {
    return 42;
}
```

يمكن لملف آخر استيراد الدالة:

```ylang
from "./math_tools.yl" import answer;

function main() -> int {
    print(answer());
    return 0;
}
```

تُحل المسارات النسبية انطلاقاً من الملف الذي يحتوي على جملة الاستيراد، وليس بالضرورة من مجلد تشغيل الطرفية.

## قواعد وحدود حالية

نظام الاستيراد ميزة تجريبية. لا يعني وجوده وجود Registry مركزي أو Dependency Solver. أسماء الاستيراد المستعارة وQualified module namespaces ليست جزءاً من العقد الحالي.

يتحقق المترجم من الأسماء المستوردة، ويبلغ عن الملفات أو الرموز غير الموجودة، ويرفض دورات الاستيراد. لا تفترض أن الاستيراد ينزّل اعتماديات من الإنترنت.

للقواعد الدقيقة، راجع [مواصفات نظام الوحدات بالإنجليزية](../reference/MODULE-SYSTEM-SPEC.md).
