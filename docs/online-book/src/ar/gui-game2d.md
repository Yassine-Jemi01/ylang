# الواجهات الرسومية وGame2D

توفر واجهات GUI وGame2D الاختيارية نافذة رسومية وأساسيات الرسم ثنائي الأبعاد. تعتمد على SDL2، لذلك لا تحتاجها برامج الطرفية العادية.

## المتطلبات والبناء

ثبت ملفات تطوير SDL2 و`pkg-config`، ثم ابنِ المكتبة والأمثلة:

```sh
make gui gui-example game2d-example
```

إذا لم يعثر `pkg-config` على SDL2، فتحقق من تثبيت حزمة التطوير لا مكتبة التشغيل فقط.

## الاستخدام

استخدم GUI عند الحاجة إلى نافذة ومدخلات لوحة المفاتيح أو الفأرة ورسم العناصر. وتوفر Game2D مساعدات لبعض العمليات مثل التصادمات وإدارة دورة اللعبة.

مثال Game2D موجود في `examples/games/dodge.yl`. شغّله من جلسة سطح مكتب رسومية بعد تثبيت SDL2.

## الحدود

- GUI وGame2D ميزتان اختياريتان وتعتمدان على SDL2.
- التشغيل الفعلي يحتاج جلسة رسومية؛ نجاح البناء في CI لا يثبت أن النافذة ستظهر للمستخدم.
- C Backend هو المسار الأساسي لهذه المكتبات.
- اختبر البرنامج على المنصة المستهدفة ولا تفترض تطابق الدعم.

للتواقيع الدقيقة، راجع [مرجع GUI API بالإنجليزية](../reference/GUI-API-SPEC.md) و[مرجع Game2D](../reference/GAME2D.md).
