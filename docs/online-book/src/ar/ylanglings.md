# التعلّم بالتطبيق مع YLanglings

YLanglings أداة تدريب تعمل دون اتصال بالإنترنت. بدلاً من الاكتفاء بقراءة الأمثلة، تحصل على برنامج صغير يحتوي على خطأ مقصود، ثم تحاول إصلاحه باستخدام المترجم الحقيقي.

## التثبيت

من جذر مستودع YLang:

```sh
make install-ylanglings PREFIX="$HOME/.local"
```

تأكد أن `$HOME/.local/bin` موجود في `PATH`، ثم جرّب:

```sh
ylanglings list
ylanglings next
```

## دورة التمرين

1. اعرض التمرين التالي باستخدام `ylanglings next`.
2. افتح ملف التمرين واقرأ الكود ورسالة الخطأ.
3. أصلح الكود مع الحفاظ على المطلوب في وصف التمرين.
4. تحقّق من الحل:

```sh
ylanglings verify 01
```

استبدل `01` برقم التمرين الذي تعمل عليه.

يمكنك طلب تلميح:

```sh
ylanglings hint 01
```

وإعادة ملف البداية:

```sh
ylanglings reset 01
```

## مسارات التعلّم

المسار الأساسي يحتوي على 16 تمريناً، ويبدأ ببنية البرنامج والمتغيرات والأنواع ثم ينتقل إلى الشروط والحلقات والدوال والمصفوفات وبقية الأساسيات.

هناك أيضاً 10 تحديات اختيارية لمواضيع أكثر تقدماً. التحديات الاختيارية منفصلة عن تقدم المسار الأساسي وليست شرطاً لإكماله.

## تنبيه أمني

الأداة تشغّل البرامج الناتجة بصلاحيات المستخدم الحالي، ولا تعمل كـ Sandbox. راجع كود أي تمرين قبل تشغيله، خصوصاً إذا لم يكن مصدره المستودع الرسمي.

## التالي
