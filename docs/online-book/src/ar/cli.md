# أوامر المترجم (CLI)

يستخدم مترجم YLang أوامر فرعية واضحة. يمكنك عرض قائمة الأوامر أو معلومات الإصدار دون فتح ملف مصدر.

## المساعدة والإصدار

```sh
ylang help
ylang --help
ylang -h
ylang version
ylang --version
ylang -V
```

كل مجموعة من الأوامر أعلاه تعطي النتيجة نفسها داخل مجموعتها. كما يعرض `ylang check --help` مرجع الأوامر.

## الأوامر الأساسية

| الأمر | الوظيفة |
|---|---|
| `ylang check FILE.yl` | تحليل المصدر وفحص الأنواع دون تشغيل مترجم C. |
| `ylang build FILE.yl [-o PATH] [--cc gcc|clang]` | توليد C وبناء ملف تنفيذي أصلي. |
| `ylang debug FILE.yl [-o PATH] [--cc gcc|clang]` | بناء مع رموز التصحيح وتشغيل GDB أو LLDB على الأنظمة المدعومة. |
| `ylang emit-c FILE.yl [-o PATH]` | حفظ كود C الناتج للفحص. |
| `ylang emit-asm FILE.yl [-o PATH]` | توليد NASM للمجموعة التجريبية المدعومة. |
| `ylang build-asm FILE.yl [-o PATH]` | تجميع وربط NASM للمجموعة المدعومة. |
| `ylang fix FILE.yl -o PATH` | تطبيق إصلاحات عالية الثقة في ملف منفصل. |

الخيار `--cc` يعمل مع `build` و`debug` فقط، ويختار GCC أو Clang لبناء البرنامج المولّد. لا يختار المترجم المستخدم لبناء YLang نفسه. ترفض الأوامر الأخرى هذا الخيار بدلاً من تجاهله.

## مسارات الإخراج

- `build` و`debug` يستخدمان `a.out` افتراضياً.
- `emit-c` يحفظ الناتج افتراضياً في `build/ylang-generated.c`.
- `emit-asm` يحفظ الناتج افتراضياً في `build/ylang-generated.asm`.
- `fix` يحتاج مساراً صريحاً باستخدام `-o` ولا يستبدل ملف الإدخال تلقائياً.

يرفض CLI خيارات الإخراج الفارغة أو المكررة، كما يرفض تكرار `--cc`. بعد استخدام `fix`، شغّل `ylang check` على الملف الناتج.

## رموز الخروج

| الرمز | المعنى |
|---:|---|
| `0` | نجاح الأمر. |
| `64` | خطأ في استخدام CLI أو أمر/منصة غير مدعومة صراحةً. |
| `65` | رفض ملف مصدر يحتوي على NUL. |
| `66` | تعذر قراءة ملف المصدر. |
| `70` | فشل تخصيص أو تجهيز مورد مطلوب. |
| `73` | تعذر إنشاء أو فتح ملف إخراج أو مجلد بناء مؤقت. |
| `74` | فشل كتابة أو إغلاق ملف ناتج من `fix`. |

قد يعيد CLI رمز خروج المترجم الأصلي عند فشل البناء. اكتب Scripts تعتمد على رمز الخروج والملف الناتج، لا على نص رسالة النجاح؛ لأن صياغة الرسائل قد تتحسن مع الإصدارات.

## مثال دورة العمل

```sh
ylang check hello.yl
ylang build hello.yl -o hello
./hello
```
