# مقدمة إلى YLang

YLang لغة برمجة مترجمة تركّز على وضوح الكود والأنواع الصريحة ورسائل الأخطاء التي تساعدك على تحديد مكان المشكلة. المترجم نفسه مكتوب بلغة C17.

## كيف تعمل؟

تمر عملية بناء البرنامج بالمراحل التالية:

1. تكتب المصدر في ملف مثل `main.yl`.
2. يفحص YLang البنية والأسماء والأنواع.
3. يولّد المترجم كود C.
4. يستدعي GCC أو Clang لتحويل كود C إلى ملف تنفيذي أصلي.

لهذا السبب تحتاج إلى مترجم C حتى لو كان برنامجك مكتوباً بالكامل بلغة YLang.

## ما الذي يميّزها؟

- التصريحات تذكر النوع بوضوح.
- فحص الأنواع والأسماء يتم قبل البناء النهائي.
- يمكن استخدام المكتبات القياسية والواجهات الموثقة.
- توجد أداة YLanglings للتعلّم من خلال إصلاح أمثلة حقيقية.

## حدود يجب معرفتها

YLang ما زالت تتطور. بعض الأجزاء مثل NASM وHTTP Streaming وTUI وGUI وعمليات الاستيراد ودعم Windows لها قيود موثقة. لا تفترض أن كل ميزة تعمل على كل نظام أو مع كل Backend.

لا تدّعي YLang حالياً امتلاك أمان ذاكرة بمستوى Rust، ولا توفر Sandbox لتشغيل كود غير موثوق. راجع التوثيق الإنجليزي للحدود التقنية الدقيقة قبل الاعتماد على ميزة تجريبية.
