# أنواع البيانات والتحويلات الصريحة

تستخدم YLang أنواعاً واضحة عند تعريف المتغيرات، مما يجعل شكل القيمة والعمليات المناسبة لها ظاهراً في المصدر.

## التصريحات

```ylang
let int count = 12;
let float ratio = 0.5;
let bool enabled = true;
let char initial = 'Y';
let byte header = byte(0x59);
let string title = "Learning YLang";
```

يأتي اسم النوع قبل اسم المتغير. من الأنواع الأساسية: `int` و`float` و`bool` و`char` و`byte` و`string`.

لإنشاء قيمة ثابتة استخدم `let const`:

```ylang
let const int MAX_USERS = 100;
```

## التحويل الصريح

- `to_float(integer)` يحوّل عدداً صحيحاً إلى قيمة عشرية.
- `to_int(float)` يحذف الجزء الكسري باتجاه الصفر، وقد يصدر خطأ إذا كانت القيمة غير منتهية أو خارج مجال `int`.
- `to_string(value)` يحوّل القيم المدعومة إلى نص.
- `string.is_int(text)` يتحقق من أن النص كله يمثل عدداً صحيحاً موقّعاً.
- `string.parse_int(text)` يحاول تحليل النص كعدد صحيح مع التعامل مع الفشل.

```ylang
function main() -> int {
    let float price = 12.9;
    let int whole = to_int(price);
    print(whole);
    return 0;
}
```

الناتج هو `12`؛ لأن `to_int` يقتطع باتجاه الصفر ولا يقرّب إلى أقرب عدد.

## التعامل مع أخطاء الأنواع

1. اقرأ التشخيص الإنجليزي كاملاً، بما في ذلك كود الخطأ ومكانه.
2. افحص نوع كل قيمة في التعبير.
3. قرر هل التصريح غير صحيح أم أن العملية تجمع نوعين غير متوافقين.
4. استخدم تحويلاً موثقاً فقط إذا كان منطق البرنامج يبرره.
5. أعد `check`، ثم ابنِ البرنامج واختبره.

`Option<T>` و`Result<T, E>` مواضيع تصميم وليستا نوعين مدعومين في اللغة حالياً. راجع [مواصفات اللغة الإنجليزية](../reference/language-spec.md) لمعرفة السلوك الدقيق.
