# المكتبة القياسية

توفر المكتبة القياسية في YLang مجموعات من الدوال للعمليات الشائعة. لا تفترض أن دالة تحمل اسماً مألوفاً من C أو Python أو Rust موجودة هنا أو أن سلوكها مطابق للغات الأخرى.

## مساحات الأسماء

- `math`: العمليات الرياضية المدعومة.
- `string`: فحص النصوص وتحليلها والتحويلات الصريحة.
- `io`: الإدخال من الطرفية وعمليات الملفات.
- `path`: عمليات وفحوصات المسارات.
- `image`: عمليات الصور المدعومة.
- `json`: تحليل JSON والتحقق منه وقراءة الحقول وتهريب النصوص وتنسيقه.
- `env.get(name)`: قراءة متغير بيئة دون تشغيل Shell.
- `http`: طلبات HTTP متزامنة وStreaming محدود باستخدام libcurl.
- `terminal`: إدخال وإخراج نصي عادي.
- `tui`: قراءة المفاتيح والتحكم بالطرفية.
- `voice`: تشغيل الصوت المحلي أو HTTP Stream عبر SDL2_mixer.

ليست كل هذه الميزات متساوية في مستوى الاستقرار. بعض الإضافات اختيارية أو تجريبية ولا تدخل ضمن ضمان التوافق الخاص بالنواة المستقرة.

## النصوص والتحقق

قد تأتي النصوص من ملف أو الطرفية أو الشبكة. لا تعتبر النص عدداً لمجرد احتوائه على أرقام. استخدم دوال التحليل والتحقق الموثقة، وتعامل مع الفشل قبل استخدام القيمة في الحسابات أو الفهارس أو المسارات.

عند التعامل مع JSON، استخدم `json.parse` أو `json.valid`، ثم أدوات الوصول المناسبة، وافحص `json.last_error()` عند الفشل. استخدم `json.escape` عند إدخال نص من المستخدم داخل JSON.

## الملفات والبيئة

استخدم دوال `io` و`path` الموثقة بدلاً من بناء المسارات يدوياً أو افتراض مجلد العمل الحالي. قد تختلف تفاصيل المسارات بين الأنظمة؛ اختبر السلوك على كل منصة يستهدفها برنامجك.

تقرأ `env.get(name)` متغير بيئة من العملية الحالية. قد تكون القيمة مفقودة أو فارغة أو غير متوقعة؛ تحقق منها ولا تطبع الأسرار في سجلات الاختبار.

للتعامل مع البايتات، راجع [Binary I/O](binary-io.md). لا تستخدم `http.stream_read` للبيانات الثنائية؛ استخدم `http.stream_read_buffer` مع byte buffers. إذا احتوى Text Stream على NUL، ينهي YLang ذلك الـ Stream ويضع تشخيصاً بدلاً من اقتطاع النص بصمت.

## JSON في 2.3

تضيف سلسلة تطوير 2.3 أدوات بناء JSON غير قابلة للتعديل مثل `json.object` و`json.array` و`json.set` و`json.push` و`json.remove`. تعيد هذه الدوال نصاً جديداً بدلاً من تعديل القيمة الأصلية. هذه الإضافات لا تزال ضمن تطوير 2.3 وليست جزءاً من الإصدار المستقر 2.2.0.

تُخزّن واجهة JSON المستند والقيم المستخرجة كنصوص JSON؛ ولا تنشئ شجرة كائنات ديناميكية. راجع [مرجع JSON بالإنجليزية](../reference/JSON.md) للحدود وسلوك المفاتيح المكررة.

## HTTP والميزات الاختيارية

تكامل HTTP تجريبي وقد يحتاج إلى libcurl. قد يفشل الاتصال أو يعيد الخادم حالة خطأ أو محتوى غير متوقعاً أو Redirect. استخدم Timeouts، وتحقق من الاستجابة، ولا ترسل بيانات الاعتماد إلى وجهة غير موثوقة. راجع [مرجع HTTP](../reference/HTTP.md) و[نموذج الأمان](../reference/SECURITY.md).

تحتاج GUI وGame2D إلى SDL2، بينما يحتاج Voice إلى SDL2_mixer أيضاً. هذه الاعتماديات ليست مطلوبة لبرامج الطرفية العادية.

C Backend هو المسار الافتراضي والأوسع تغطية. NASM Backend تجريبي ويدعم مجموعة أضيق. نجاح `check` لا يضمن أن كل Backend يستطيع بناء البرنامج. للتواقيع الدقيقة، راجع [مواصفات اللغة الإنجليزية](../reference/language-spec.md).
