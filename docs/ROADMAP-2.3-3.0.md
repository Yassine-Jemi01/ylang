# Superseded: YLang 2.3 → 3.0 roadmap

This proposal has been superseded by the unified [YLang 3.0 roadmap](ROADMAP-3.0.md).

**Release decision:** YLang will develop the proposed language changes and native backend work directly toward YLang 3.0. No separate 2.3 stable release is planned.

The detailed language design is in [RFC-3.0-LANGUAGE-DESIGN.md](RFC-3.0-LANGUAGE-DESIGN.md), and LLVM implementation requirements are in [RFC-3.0-LLVM-BACKEND.md](RFC-3.0-LLVM-BACKEND.md).
