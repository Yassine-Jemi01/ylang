# Online book

The YLang Book is now maintained as an online book at [the YLang learning site](https://yassine-jemi01.github.io/ylang/learn/index.html).

The online edition is the canonical source for tutorials and the language guide. It combines the step-by-step learning path with the detailed technical references maintained alongside the compiler. Please edit the Markdown sources in \`docs/online-book/src/\` and preserve the existing mdBook theme and navigation.

The old standalone PDF edition is retired. Do not regenerate or link to \`YLang-Book.pdf\`; expand and correct the online chapters instead.
