1. Install the build requirements

YLang's compiler is written in C17 and uses GNU Make. Building a YLang program also requires GCC or Clang.

Fedora

sudo dnf install gcc make clang
git clone https://github.com/Yassine-Jemi01/ylang.git
cd ylang
make
make test

macOS

xcode-select --install
brew install make llvm
git clone https://github.com/Yassine-Jemi01/ylang.git
cd ylang
gmake
gmake test

Use GNU Make (gmake) rather than Apple's built-in BSD Make.

These are source-build instructions, not a prebuilt installer. Check the repository README for current platform notes.

2. Your first YLang program

function add(int a, int b) -> int {
    return a + b;
}

function main() -> int {
    let const string language = "YLang";
    print("Hello from", language);
    print("2 + 3 =", add(2, 3));
    return 0;
}

Save it as hello.yl, then run:

./build/ylang check hello.yl
./build/ylang build hello.yl -o hello
./hello

YLang uses explicit types and explicit conversions. The stable build path generates C and invokes GCC or Clang; the NASM backend is experimental and supports a smaller subset.

Know what is implemented

The stable 1.1.0 release remains available. This 2.0.0-beta.1 preview adds experimental multi-file imports, typed enums, typed structs, and SDL2-backed 2D helpers. The C backend remains the default; NASM supports only a restricted experimental subset. Option/Result is not implemented, and these source-build instructions do not promise prebuilt binaries.
