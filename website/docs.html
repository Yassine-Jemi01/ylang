03 / COMPILER

Build and test from source.

The supported development targets are Linux and macOS. You need a C17 compiler and GNU Make. GUI examples also need SDL2 development files and pkg-config.

Full setup instructions ↗
TERMINAL
git clone https://github.com/Yassine-Jemi01/ylang.git
cd ylang
make
make test
./build/ylang --version
IMPORTANT

Experimental does not mean complete.

The C backend remains the default compiler path. NASM is limited to a restricted subset and remains experimental. Option<T> and Result<T, E> are design proposals, not implemented language features. The beta does not claim Rust-level memory safety, native Windows support, or production stability. No prebuilt installers are included in the source-only beta.
