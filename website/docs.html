03 / TOOLCHAIN

Build from source.

Linux and macOS are the primary tested targets. Experimental native Windows x86-64 support uses MinGW-w64. GUI and Game2D examples require SDL2 development files and pkg-config.

Full setup instructions ↗
TERMINAL
git clone https://github.com/Yassine-Jemi01/ylang.git
cd ylang
make
make test
./build/ylang --version
NOTE

Experimental does not mean complete.

The C backend remains the default. NASM supports a restricted experimental subset. Native Windows support is experimental and currently tested through a focused MinGW-w64 smoke suite. Option<T> and Result<T, E> are design proposals, not implemented features. Experimental extensions are not covered by the stable-core compatibility guarantee; YLang does not make a Rust-level memory-safety or sandbox claim.
