# YLang website

A lightweight, static landing page built with HTML, CSS, and vanilla JavaScript.

## Preview locally

Open `index.html` in a browser, or serve this directory with any static file server. No npm install or build step is required.

## Publishing

The site lives in `website/`. It is not automatically live just because the files are in the repository. To publish it, configure GitHub Pages to serve the `website/` directory or add a deployment workflow after the repository's Pages settings are ready.

The downloads section intentionally links to the GitHub Releases page and explains that prebuilt installers are not published yet. Replace that notice only after release artifacts and checksums exist.
