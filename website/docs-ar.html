وثائق YLANG

تعلّم اللغة، وافهم الأدوات.

04 / البناء

ابنِ YLang من المصدر.

Linux وmacOS هما المنصتان الأساسيتان للاختبار. دعم Windows الأصلي ما زال تجريبياً ويستخدم MinGW-w64. أمثلة الواجهات الرسومية وGame2D تحتاج ملفات تطوير SDL2.

دليل التثبيت بالعربية ←
الطرفية
git clone https://github.com/Yassine-Jemi01/ylang.git
cd ylang
make
make test
./build/ylang --version
تنبيه

التجريبي لا يعني الاكتمال.

C Backend هو المسار الافتراضي. NASM يدعم مجموعة محدودة وتجريبية. دعم Windows الأصلي ما زال تجريبياً. لا يدّعي YLang امتلاك أمان ذاكرة بمستوى Rust ولا يوفر Sandbox. رسائل المترجم وأكواد الأخطاء وأسماء API تبقى باللغة الإنجليزية.
