Familiar to read. Built to be explored.

YLang brings approachable syntax to a small compiled language project. Its implementation is open, so the design decisions are part of the learning experience too.

Readable code

Familiar control flow and function signatures keep programs approachable without hiding how they work.

Explicit types

Types and conversions are visible in the code, with diagnostics designed to help you understand mistakes.

A compiler you can inspect

The stable path generates C and uses GCC or Clang. The NASM backend remains experimental and limited.

From a .yl file to a native program

The compiler has two paths. The C path is the stable one. The NASM path is experimental and covers less of the language.
