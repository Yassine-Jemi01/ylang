01 / The language

Familiar to read.
Built to be explored.

YLang brings approachable syntax to a small compiled language project. Its implementation is open, so the design decisions are part of the learning experience too.

01{ }

Readable code

Familiar control flow and function signatures keep programs approachable without hiding how they work.

02T

Explicit types

Types and conversions are visible in the code, with diagnostics designed to help you understand mistakes.

03</>

A compiler you can inspect

The stable path generates C and uses GCC or Clang. The NASM backend remains experimental and limited.

Project statusYLang is still evolving. Feature coverage and its safety model are not equivalent to Rust, and support varies by backend.

03 / Get started

Build it from
the source.

Prebuilt installers are not published yet. To try YLang today, clone the repository and build the current compiler.

View releases → Build instructions ↗
TerminalLinux / macOS

$ git clone https://github.com/Yassine-Jemi01/ylang.git

$ cd ylang

$ make

$ make test

Requires a C17 compiler and GNU Make. See the README for platform notes.
