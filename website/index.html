01 / The language

Familiar to read.
Interesting to build.

YLang takes inspiration from expressive, approachable syntax while exploring the design choices behind a compiled language.

01

Readable code

A clean, Python-inspired surface syntax with explicit function signatures and familiar control flow.

02

Explicit types

Types and conversions are visible in your code instead of being silently guessed for you.

03

A real compiler

The current stable path generates C and uses GCC or Clang. An x86-64 NASM backend is experimental.

Still evolving: YLang is an early-stage project. Its safety model and feature coverage are not yet equivalent to Rust, and backend support varies by feature.

02 / Start learning

Start with the
source.

Explore the compiler, read the language guide, or build the current version locally.

Browse the documentation ↗ Read the official YLang book (PDF) ↗
1

Get the source

Clone the public repository.

git clone https://github.com/Yassine-Jemi01/ylang.git
cd ylang
2

Build the compiler

On Linux or macOS, install a C compiler and make.

make
3

Run the tests

Check your build before trying examples.

make test

Requirements and platform-specific details are documented in the repository README. These commands are for building from source, not a prebuilt installer.
