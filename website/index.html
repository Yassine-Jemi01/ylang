THE TOOLCHAIN

From source to executable.

The C backend is the default. NASM support is experimental and currently covers a more limited subset of the language.

STEP 01 YLang source hello.yl
STEP 02 YLang compiler Parse and type-check
STEP 03 Generated C Readable intermediate output
STEP 04 GCC or Clang Native executable

i YLang keeps the compilation path visible instead of hiding the tools that build your program.

TAKE IT FOR A SPIN

Start with your own code.

Linux and macOS are the primary tested targets. Install a C17 compiler and GNU Make, build YLang from source, and run the test suite.
