THE LANGUAGE

Designed to be understood.

YLang is also a compiler project: the implementation is part of what you can learn, inspect, and improve.

01

Readable by design

Familiar function signatures and control flow keep the source approachable while making program structure visible.

02

Types are explicit

Conversions are deliberate. Diagnostics identify errors in your source and aim to explain what needs attention.

03

Follow the toolchain

The default backend emits C and invokes GCC or Clang. You can inspect generated code instead of treating compilation as a black box.

FROM SOURCE TO EXECUTABLE

A build process you can trace.

The C backend is the default path. The NASM backend is experimental and supports only a restricted subset of the language.

GET STARTED

Build from source.

YLang targets Linux and macOS. Install a C17 compiler and GNU Make, then build the compiler and run its tests.

Build instructions ↗ All releases ↗
